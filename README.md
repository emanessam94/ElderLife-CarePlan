ElderLife AI - Care Plan & Health Routine Module

This repository contains the Care Plan & Health Routine module for the ElderLife AI platform. It handles elderly profile management, daily routine tracking, and alert rules for caregivers.

Live Demo
You can try the live version here: https://elderlife-delta.vercel.app/

What this module does
- Displays elderly profiles and their personalized care plans.
- Tracks daily schedules including medications, meals, hydration, and check-in tasks.
- Logs missed or delayed routines for caregiver monitoring.
- Triggers reminder alerts based on activity rules.
- Designed strictly to monitor safety patterns without making medical diagnoses or auto-adjusting dosages.

Tech Stack
- React
- TypeScript
- Tailwind CSS
- Deployed on Vercel
